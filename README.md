## PARA RODAR O PROJETO, NO TERMINAL, NA PASTA IHC-Lumina:

```
Clone o repositorio github
-> git clone https://github.com/outz1/IHC-Lumina

Baixar as dependencias
-> npm install

Rodar o script
-> npm run dev
```
### O RELATÓRIO
Presente em relatorio-prompts-interface.pdf

### ONDE VER O PROJETO?
O projeto roda em http://localhost:8443/

Arquivos principais:
- index.html (shell HTML e fonte Poppins)
- src/style.css (visual e transição)
- src/App.tsx (estrutura e interações, em React + TypeScript) (é o codigo de script.js mas em react)
